كيف يعمل

جاهز في 4 خطوات

من الصفر إلى النشر على LinkedIn في دقائق

1

أنشئ LinkedIn Developer App

اذهب إلى linkedin.com/developers وأنشئ تطبيقاً للحصول على Client ID وClient Secret.

2

أضف الإعداد لـ Claude Desktop

أضف سطرين فقط في ملف الإعدادات مع بيانات تطبيقك LinkedIn.

3

سجّل الدخول بـ OAuth مرة واحدة

اطلب من المساعد رابط التفويض، افتحه في المتصفح مرة واحدة فقط.

4

انشر بأمر واحد! 🎉

قل للمساعد: "انشر على LinkedIn..." والباقي يحدث تلقائياً.

claude_desktop_config.json
{ "mcpServers": { "linkedin": { "command": "npx", "args": ["-y", "linkedin-post-mcp@latest"], "env": { "LINKEDIN_CLIENT_ID": "your_client_id", "LINKEDIN_CLIENT_SECRET": "your_client_secret" } } } }
